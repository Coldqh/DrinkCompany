# Drink Company — рабочее название

Мобильная PWA-стратегия про производство пива и сидра, разработку рецептур, живой рынок и постепенное развитие компании.

## Рабочий вертикальный срез 0.3.0

- открытие компании в реальной стране и регионе;
- стандартный и жёсткий режим;
- покупка варочного порядка, яблочного пресса, ферментеров, лаборатории и линии розлива;
- редактор рецептуры с вкусовым профилем и технологическими параметрами;
- отдельные стили пива и сидра;
- расчёт себестоимости и ограничений оборудования;
- живые партии: ферментация, созревание, готовность, дегустация, розлив или списание;
- дегустационные выводы из фактических свойств партии;
- рецептурный архив с версиями;
- 12 постоянных баров, магазинов и специализированных точек;
- отправка образцов и личные встречи с закупщиками;
- разные технические, вкусовые, ценовые и объёмные требования;
- объяснимые отказы, встречные офферы, контракты и первая продажа;
- складской остаток, выручка, отношения и коммерческий архив;
- 12 компаний мира разных отраслей, их релизы, полки и изменение импульса;
- автоматическое сохранение в IndexedDB и JSON-экспорт;
- автоматическая публикация через GitHub Pages.

## Запуск и проверка

```bash
npm ci
npm run dev
npm test
npm run lint
npm run build
```

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` при каждом push в `main` проверяет проект, собирает `dist` и публикует его.

Адрес:

`https://coldqh.github.io/DrinkCompany/`

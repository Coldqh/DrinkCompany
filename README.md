# Drink Company — рабочее название

Мобильная PWA-игра про производство пива и сидра, разработку рецептур, поиск покупателей и постепенное развитие компании.

## Стек

- React
- TypeScript
- Vite
- IndexedDB
- GitHub Pages
- ручной Service Worker без обязательного полного офлайна

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm test
npm run lint
npm run build
```

## Текущий вертикальный срез

- создание компании;
- стандартный и жёсткий режим;
- выбор реальной страны и региона;
- выбор объекта;
- списание стартовых и ежедневных расходов;
- переход времени по дням;
- мобильная навигация;
- локальное автосохранение;
- экспорт и импорт сохранения.

Следующий срез: оборудование и первая настройка рецептуры пива.

# PROJECT.md — память проекта

## Название и цель

- Рабочее название: Drink Company. Финальное название будет выбрано отдельно.
- Пользовательская проблема: игры про производство напитков обычно сводят рецептуру к готовым рецептам или линейным бонусам.
- Основной пользователь: игрок, которому интересны производство, рецептуры, рынок и постепенное развитие компании.
- Ключевой результат: каждая партия создаётся решениями игрока, а её коммерческий результат зависит от продукта и конкретных покупателей.

## Текущий статус

- Версия: 0.2.0
- Работает: создание компании, реальные страны и регионы, выбор объекта, два режима сложности, оборудование, глубокий редактор пива и сидра, запуск партий, течение стадий по дням, дегустация, розлив, рецептурный архив, динамическая экосистема компаний, IndexedDB и JSON-экспорт.
- Ближайшая цель: образцы, переговоры, требования баров и магазинов, контракты и первая реальная продажа.

## Стек

- Языки: TypeScript, CSS, HTML.
- Клиент: React + Vite.
- Сервер: отсутствует.
- Хранилище: IndexedDB, JSON-экспорт.
- Инфраструктура: GitHub Pages, PWA, GitHub Actions.
- Тесты: Vitest.

## Архитектура

- Доменные модули: игра, производство, рецепты, партии, рынок, архив.
- Источник истины: единый `GameState` версии 2 в доменном слое.
- Производственные расчёты: `src/domain/production.ts`, без зависимости от React.
- UI: только отображает состояние и вызывает доменные переходы.
- Миграция: сохранения schemaVersion 1 автоматически переходят на schemaVersion 2.
- Критические данные: деньги, оборудование, рецепты, партии, бутылочный склад, история мира.

## Ограничения

- Главная платформа: телефон, вертикальная ориентация.
- Без аккаунтов и сервера.
- PWA устанавливается, полный офлайн не гарантируется.
- Запрещено: Godot, GDScript, зависимость проекта от Cursor, бизнес-логика в UI, фиксированные оптимальные рецепты.

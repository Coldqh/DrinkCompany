# Feature Spec 023 — качество, сертификация и отзыв партий

## Проблема

Товар можно проследить по цепочке, но мир не умеет проверять безопасность, выдавать сертификаты и изымать конкретные опасные бутылки.

## Наблюдаемое поведение

- лаборатории принимают образцы с ограниченной дневной мощностью;
- анализ создаёт измерения и оплачивается заказчиком;
- успешный результат создаёт сертификат;
- провал создаёт инцидент, отзывает затронутые лоты и приостанавливает продукт и контракты;
- успешный повторный выпускной анализ закрывает инцидент и возобновляет оборот;
- уничтоженный товар исчезает со склада, перевозки и полки и записывается в kernel.

## Критерии приёмки

- [x] один источник истины для качества — `EcosystemState.quality`;
- [x] правила анализов data-driven по категории напитка;
- [x] конкретные lot allocations проходят через перевозку и полку;
- [x] отзыв не создаёт отрицательных остатков;
- [x] лабораторные и recall-платежи идемпотентны;
- [x] старые сохранения мигрируют без потери товарной сети;
- [x] observer-run проходит без нарушений.

## Негативные сценарии

- образец с неизвестным продуктом отменяется;
- отозванный лот не считается доступным;
- активный груз затронутого продукта останавливается;
- сертификаты продукта отзываются после провала;
- слабый вкус без нарушения безопасности не вызывает автоматический отзыв.

## Не входит

- страховые полисы и судебные иски;
- государственная система массовых публичных уведомлений;
- ручной геймплей отбора образца игроком;
- отдельные отраслевые панели для каждого вида алкоголя.

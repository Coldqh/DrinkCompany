# Feature 001 — старт компании

## Наблюдаемое поведение

Игрок создаёт компанию, выбирает режим, реальную страну, регион и объект. Игра списывает стоимость объекта, показывает ежедневные расходы и открывает основную оболочку.

## Критерии приёмки

- название короче двух символов не принимается;
- объект дороже стартового капитала нельзя выбрать для старта;
- выбранный объект и финансы сохраняются в IndexedDB;
- обновление страницы восстанавливает игру;
- экспорт создаёт JSON, импорт восстанавливает состояние;
- переход дня списывает ежедневные расходы;
- интерфейс работает в вертикальной мобильной ширине от 320 px.

## Не входит

- оборудование;
- рецептура;
- партии;
- покупатели и другие компании;
- сервер и аккаунты.

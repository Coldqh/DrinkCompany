# Feature Spec 006 — компактный мобильный интерфейс

## Проблема

Основные разделы выводили все данные одним длинным полотном. На экране iPhone 14 Pro не было ясного текущего решения, карточки выглядели однообразно, а важные действия терялись среди вторичной информации.

## Наблюдаемое поведение

- каждый главный раздел открывается компактной сводкой;
- подробности разделены по подвкладкам;
- карточки списков показывают только ключевой статус;
- нажатие на оборудование, партию, покупателя, переговоры, компанию, рецепт или продажу открывает отдельное окно;
- модальные окна имеют собственную вертикальную прокрутку;
- основной раздел всегда допускает прокрутку вверх и вниз;
- следующий день и нижняя навигация остаются доступными независимо от длины раздела.

## Критерии приёмки

- [x] компания разделена на «Сегодня / База / Путь»;
- [x] производство разделено на «Линия / Рецепт / Запуск»;
- [x] рецепт разделён на «Основа / Вкус / Процесс»;
- [x] партии разделены на «В работе / Решения / История»;
- [x] рынок разделён на «Сбыт / Сделки / Мир»;
- [x] архив разделён на «Рецепты / Продажи / Данные»;
- [x] детали и действия перенесены в модальные окна;
- [x] сохранено всё существующее игровое поведение;
- [x] TypeScript, тесты и production-сборка проходят.

## Негативные сценарии

- пустые списки показывают компактное состояние и следующий доступный шаг;
- окно закрывается по кнопке, клику по фону или Escape;
- при открытом окне фон не прокручивается;
- длинное содержимое окна прокручивается независимо;
- действия рынка и партий продолжают показывать доменные ошибки.

## Не входит в задачу

- новая игровая механика;
- изменение баланса;
- серверное хранение;
- финальный брендинг и название игры.

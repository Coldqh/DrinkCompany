# Bugfix 031.2 — UX Consolidation

## Проблема

Интерфейс 0.27.0 визуально обновил приложение, но сохранил дублирующие команды и неясные переходы. Несколько элементов вели в один сценарий, каталог поставщиков скрывал ассортимент, а вторичные данные мира конкурировали с главными действиями.

## Наблюдаемое поведение

- новая партия запускается только одной явной кнопкой;
- рецепты, партии и розлив являются разделами, а не скрытыми командами запуска;
- недостающее сырьё заказывается из требований конкретной партии;
- поставщики показывают ассортимент, цену, качество и доставку в общем списке;
- пустые состояния не дублируют навигацию;
- вторичные сведения мира раскрываются по запросу;
- CSS использует только `--font-title`, `--font-body` и `--font-data`.

## Критерии приёмки

- [x] отсутствуют кнопки «Проверить производство», «Открыть поставщиков» и «Сделать заказ» в пустых состояниях;
- [x] нажатие на вкладки производства не запускает партию;
- [x] из финального шага рецептуры можно открыть подходящие предложения и оформить заказ;
- [x] ассортимент поставщиков виден до открытия модального окна заказа;
- [x] все декларации `font-size` используют один из трёх токенов;
- [x] сохранения и доменные переходы не изменены.

## Негативные сценарии

- при отсутствии подходящего предложения показывается понятная ошибка;
- нельзя оформить заказ ниже минимума или выше доступного остатка;
- партию нельзя запустить до доставки недостающего сырья;
- длинные названия поставщиков и продуктов обрезаются без горизонтального переполнения.

## Изменённые границы

Только презентационный слой. `GameState`, доменные владельцы данных, экономика и `schemaVersion 25` остаются без изменений.

## Откат

Удалить файлы патча 031.2 и восстановить версии интерфейсных компонентов из 0.27.1. Миграция данных не требуется.

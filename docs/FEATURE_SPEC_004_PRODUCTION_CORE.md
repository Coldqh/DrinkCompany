# Feature Spec 004 — производственное ядро и новый мобильный интерфейс

## Наблюдаемое поведение

1. Игрок покупает оборудование за деньги компании.
2. Пиво требует варочный порядок и ферментеры, сидр — пресс и ферментеры.
3. Игрок создаёт рецепт через стиль, профиль вкуса, объём, температуру и длительность этапов.
4. Запуск партии списывает рассчитанную стоимость сырья.
5. Партия меняет стадию только при переходе игровых дней.
6. После готовности игрок проводит дегустацию и получает объяснимые сильные и слабые стороны.
7. Продегустированная партия может быть разлита при наличии линии или списана.
8. Сохранённые рецепты и партии переживают перезапуск приложения.
9. Старое сохранение schemaVersion 1 мигрирует без потери компании и денег.
10. Компании мира существуют в `GameState` и меняют состояние по дням.

## Критерии приёмки

- [x] Нет производственных заглушек в основных вкладках.
- [x] Пиво и сидр используют разные обязательные модули и стили.
- [x] Нет одного скрытого «рейтинга рецепта» в UI до дегустации.
- [x] Доменная логика не находится в React-компонентах.
- [x] Нельзя запустить партию без оборудования, денег или свободной мощности.
- [x] Нельзя разлить партию без дегустации и линии розлива.
- [x] Unit-сценарий проходит полный путь до бутылочного склада.
- [x] TypeScript, тесты и production build проходят.

## Не входит в задачу

- контракты с точками;
- реальные продажи и повторные заказы;
- сотрудники;
- купажирование и переработка слабой партии;
- полноценная лабораторная мини-игра;
- серверные аккаунты.

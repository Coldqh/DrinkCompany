# Feature Spec 014 — товарный оборот экосистемы

## Проблема

Организации и объекты существовали в общей модели, но ежедневная выручка NPC рассчитывалась абстрактно. Продукт не проходил путь от сырья до конкретной полки.

## Наблюдаемое поведение

- поставщики хранят и пополняют реальные лоты сырья;
- производитель получает сырьё только через поставку;
- запуск NPC-партии списывает существующие лоты;
- готовая партия создаёт складской остаток продукта;
- контракт создаёт перевозку с датой прибытия;
- доставка продукта пополняет полку конкретного бара или магазина;
- конечная продажа уменьшает остаток и переводит деньги оператору точки;
- дефицит, задержка или нехватка денег нарушают поставку;
- слабый продукт может быть снят с производства;
- новый релиз становится отдельным продуктом мира.

## Критерии приёмки

- [x] у товара есть владелец, количество и место хранения;
- [x] NPC не производит без сырья;
- [x] товар не появляется на полке без доставки;
- [x] выручка возникает только после поставки или конечной продажи;
- [x] экран мира показывает перевозки, продукты и узкие места;
- [x] сохранения v10 мигрируют на v11.

## Негативные сценарии

- товар закончился у поставщика;
- покупатель не может оплатить доставку;
- производству не хватает сырья;
- полка остаётся пустой;
- продукт имеет слабый оборот и снимается с производства.

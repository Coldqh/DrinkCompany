# Feature Spec 005 — рынок, экосистема и первая продажа

## Проблема

Разлитая партия не должна превращаться в деньги одной кнопкой. Игроку нужен конкретный покупатель со своей аудиторией, требованиями, ценой и риском отказа.

## Наблюдаемое поведение

- в мире существуют 12 постоянных баров и магазинов;
- каждая точка имеет канал, аудиторию, требования, ценовой диапазон, размер заказа, отношения и текущих поставщиков;
- игрок выбирает разлитую партию, цену, объём и способ контакта;
- образцы списываются со склада, переговоры стоят денег;
- решение приходит через несколько игровых дней;
- точка оценивает техническую чистоту, дефекты, стиль, характер, понятность, цену, репутацию и отношения;
- результатом становится объяснимый отказ или конкретный оффер;
- принятие оффера создаёт контракт и продажу, меняет деньги, склад, репутацию и отношения;
- поставки сохраняются в коммерческом архиве;
- сторонние производители занимают места на полках и продолжают менять рыночный импульс.

## Критерии приёмки

- [x] нельзя отправить неразлитую партию;
- [x] нельзя обещать больше бутылок, чем есть на складе;
- [x] нельзя дублировать активное предложение одной точке по одной партии;
- [x] несовместимая категория или провал обязательного требования даёт отказ;
- [x] оффер содержит цену и фактический объём;
- [x] продажа проводит деньги и уменьшает остаток атомарно;
- [x] сохранение версии 2 автоматически мигрирует на версию 3;
- [x] основной поток покрыт тестом.

## Негативные сценарии

- недостаточно денег на переговоры;
- недостаточно бутылок с учётом образцов;
- точка не принимает категорию продукта;
- техническая чистота или риск дефектов не проходят порог;
- партия распродана до принятия второго оффера;
- повреждённое старое сохранение не создаёт фиктивную продажу.

## Данные и состояние

Источник истины — `GameState schemaVersion 3`.

Рынок хранит:

- точки сбыта;
- предложения;
- контракты;
- продажи;
- отношения;
- компании мира;
- рыночную ленту.

## Не входит в задачу

- регулярные повторные заказы;
- торг в несколько раундов;
- дистрибьюторы;
- логистика и сроки доставки;
- возвраты и штрафы за нестабильность следующих партий.

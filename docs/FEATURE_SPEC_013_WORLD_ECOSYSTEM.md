# Feature Spec 013 — единая экосистема мира

## Проблема

Бары, магазины и собственная розница существовали как разные панели и не были частью общей экономики.

## Наблюдаемое поведение

- каждая рыночная точка связана с объектом и организацией-владельцем;
- игрок может выкупить действующий объект, арендовать свободный или купить долю организации;
- операционный контроль и долевое владение имеют разные последствия;
- NPC-компании ежедневно получают выручку, несут расходы и обслуживают долг;
- неплатёжеспособность выставляет активы на продажу;
- NPC могут поглощать проблемные объекты;
- старые собственные точки мигрируют в объекты экосистемы.

## Критерии приёмки

- [x] один владелец данных для организаций, объектов, долей и сделок;
- [x] существующий бар можно выкупить;
- [x] свободный объект можно арендовать;
- [x] инвестиция не передаёт операционный контроль;
- [x] мир меняется при переходе дня без действий игрока;
- [x] рыночная точка после выкупа перестаёт быть внешним покупателем;
- [x] сохранения v9 мигрируют в v10.

## Негативные сценарии

- недостаточно денег;
- попытка купить собственный объект;
- попытка открыть точку без свободной недвижимости;
- покупка доли больше 49%;
- предложение товара точке, уже принадлежащей игроку.

## Не входит в задачу

- полный рынок труда NPC;
- акционерные голосования;
- банковские кредиты;
- строительство здания с нуля;
- серверная многопользовательская экономика.

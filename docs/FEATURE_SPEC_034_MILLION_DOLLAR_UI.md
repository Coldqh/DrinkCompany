# Feature 034 — Million-Dollar Mobile UI

## Цель

Перенести утверждённое визуальное направление в реальные компоненты Drink Company без подмены игровой логики статическими макетами. Интерфейс ориентирован на iPhone 14 Pro, сохраняет существующие действия и использует фактическое состояние мира.

## Реализованные экраны

- **Производство** — обзор компании, проблем, процессов, ближайшего события, партий, дефицитов, поставок и объекта.
- **Выбор бутылки** — интерактивный конструктор формы, стекла, объёма, укупорки, этикетки и тиснения. Бутылка полностью построена CSS-примитивами.
- **Профиль компании** — финансы, активы, бренды, команда, лицензии и сохранения в полноэкранном профиле.
- **Коктейльный клуб** — смена, меню, бар, склад, сервис и реальные данные hospitality-сектора.
- **Новый коктейль** — изолированный пятиэтапный сценарий без нижней навигации.
- **Рынок ингредиентов** — поиск, сортировка, поставщики, предложения, договоры, заказы и склад.

## Архитектурные решения

- Визуальные сущности вынесены в `LuxuryPrimitives`: герб, бутылка, коктейль, ингредиент, рейтинг и кольцевой показатель.
- Новая система стилей изолирована в `luxury-ui.css` и подключается последней, поэтому не меняет доменные модели и миграции сохранений.
- Все управляющие кнопки вызывают существующие callbacks контроллера.
- Производство, рынок, компания и клуб используют реальные коллекции `GameState`; демонстрационные fallback-элементы клуба применяются только при пустом меню.
- Полноэкранные сценарии сообщают оболочке о своём состоянии через `onFlowChange`, чтобы скрывать нижнюю навигацию.

## Совместимость

- `schemaVersion` не изменён.
- Новых данных в сохранение не добавлено.
- Старые сохранения продолжают загружаться без миграции.

# Feature Spec 033 — Mobile Visual System

## Проблема

Мобильная оболочка превратилась в перегруженный dashboard: вложенные карточки, лишние изображения, несогласованная типографика, горизонтальные переполнения и действие завершения дня внутри навигации.

## Наблюдаемое поведение

- приложение использует один системный шрифт;
- мобильная типографика ограничена ролями 28/34, 18/24, 15/21, 13/18 и 22/28;
- основной горизонтальный отступ равен 20 px;
- обычные карточки не имеют радиус больше 16 px;
- экран «Сегодня» помещает состояние, проблемы, процессы и ближайшее событие в 390×844;
- нижняя навигация содержит четыре раздела и только один активный пункт;
- завершение дня является отдельной кнопкой над навигацией;
- производство и мир используют собственный горизонтальный скролл вкладок без переполнения документа;
- новый выпуск остаётся полноэкранным пошаговым сценарием без нижней навигации.

## Сохранённые контракты

Игровые переходы, GameState, schemaVersion, доменные вычисления и существующие действия не изменяются.

## Проверка

Визуальная проверка выполнена в Chromium на 390×844 для экранов «Сегодня», «Производство», «Торговля», «Мир» и сценария нового выпуска.

# Bugfix 032.1.1 — Production build

## Проблема

После пересборки production UX компонент `ProductionOverview` обращался к `state.facility.cleanliness`, хотя `FacilityState` хранит санитарное состояние в поле `sanitation`, а сам `facility` может быть `null`. В том же файле остался неиспользуемый импорт `getIngredient`. Строгая TypeScript-сборка блокировала deploy.

## Исправление

- `cleanliness` заменён на `sanitation`;
- чтение объекта выполнено через optional chaining;
- при отсутствии объекта обзор показывает `0/100` и подпись «объект не выбран»;
- удалён неиспользуемый импорт.

## Риски

Низкие. Изменена только UI-проекция уже существующего состояния. Доменные переходы, сохранения и вычисления не затронуты.

## Проверка

- исходные compile-аннотации устранены статически;
- проверено отсутствие обращений к `facility.cleanliness`;
- проверено отсутствие импорта `getIngredient` в `ProductionStudio.tsx`;
- `git diff --check` проходит.

# Feature Spec 028 — Hospitality Ecosystem

## Проблема

После появления универсального производства напитков бары и клубы оставались обычными торговыми полками. Мир не учитывал открытые бутылки, кеги, порционный расход, меню, работу смены и реальные ограничения обслуживания.

## Наблюдаемое поведение

- В мире существуют пабы, коктейльные бары, клубы, рестораны, отельные и винные бары, лаунжи и музыкальные площадки.
- Каждое заведение закупает реальные коммерческие продукты.
- Закрытая упаковка открывается и расходуется в миллилитрах.
- Меню формируется из доступных продуктов и cocktail recipes.
- Смена создаёт гостей, заказы, выручку, себестоимость, отходы, ожидание и инциденты.
- Порционная продажа сохраняет происхождение использованных лотов.
- При отсутствии товара заведение не создаёт продажи из воздуха.

## Критерии приёмки

- [x] Все форматы заведения представлены организациями и недвижимостью.
- [x] Списание упаковки и миллилитров происходит физически.
- [x] Коктейль использует несколько реальных продуктов, когда они доступны.
- [x] Смена изменяет кассу оператора и состояние заведения.
- [x] Hospitality-продажи не дублируются старой розничной формулой.
- [x] Kernel регистрирует serve и source lots.
- [x] Старые сохранения автоматически получают hospitality-сектор.
- [x] Аренда и покупка заведения сразу обновляют его hospitality-оператора.
- [x] Собственный релиз игрока можно передать в реальный запас заведения и продавать порциями.

## Негативные сценарии

- пустой склад;
- истёкшая открытая бутылка;
- недостаток конкретного ингредиента коктейля;
- перегрузка барных станций;
- нехватка персонала;
- задержка поставки;
- инцидент безопасности;
- закрытое или приостановленное заведение.

## Данные и состояние

- `HospitalityVenueState` — формат, мощность, команда и показатели заведения;
- `HospitalityMenuItemState` — позиция меню и её ингредиенты;
- `HospitalityOpenContainerState` — открытая бутылка или кег;
- `HospitalityShiftReportState` — результат конкретной смены;
- `HospitalityIncidentState` — объяснимое нарушение работы.

## Не входит в задачу

- полная библиотека сотен коктейлей;
- ручная работа бармена в реальном времени;
- авторские коктейльные тренды;
- кухня ресторана;
- подробное расписание по часам;
- отдельный UI-раздел управления баром.

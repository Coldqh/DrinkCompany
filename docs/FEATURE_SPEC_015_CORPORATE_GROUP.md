# Feature Spec 015 — корпоративная группа

## Проблема

Покупка доли компании не давала контроля, а покупка отдельного объекта разрушала смысл действующей организации. Игроку нужна возможность приобретать работающую компанию вместе с её активами, контрактами, сотрудниками и товарными потоками.

## Наблюдаемое поведение

- миноритарная доля не даёт операционного контроля;
- пакет от 51% создаёт дочернюю компанию;
- дочерняя компания остаётся самостоятельной организацией экосистемы;
- её продукты, контракты, склады, перевозки и объекты продолжают работать;
- игрок задаёт автономность и казначейскую политику;
- можно докапитализировать проблемную компанию;
- активы можно передавать только между контролируемыми организациями;
- NPC не выкупают активы компаний группы через фоновую процедуру.

## Критерии приёмки

- [x] доступны контрольные пакеты 51%, 75% и 100%;
- [x] стоимость учитывает текущую долю, состояние компании и премию за контроль;
- [x] дивиденды реально списываются с денег организации;
- [x] дочерние компании видны в отдельном разделе группы;
- [x] сохранения schemaVersion 11 мигрируют в 12;
- [x] старые экосистемы получают пустой список дочерних компаний.

## Негативные сценарии

- недостаточно денег;
- повторная покупка уже имеющегося пакета;
- докапитализация неконтролируемой компании;
- перевод актива за пределы группы;
- перевод актива его текущему владельцу.

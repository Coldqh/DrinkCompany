# Feature Spec 016 — стратегии, руководители и память мира

## Проблема

Организации владеют активами и товарными цепочками, но без целей и памяти их решения выглядят механическими и не образуют историю.

## Наблюдаемое поведение

- каждая организация имеет активных руководителей с разными чертами;
- компания выбирает стратегию из своего финансового состояния, отрасли, руководства и прошлых провалов;
- стратегия меняет реальные продукты, цены, долги, расходы и контракты;
- срывы поставок и сделки формируют память и отношения между организациями;
- слабое руководство может быть заменено;
- важные решения сохраняются в общей хронике;
- старые сохранения получают безопасно созданный слой интеллекта.

## Критерии приёмки

- [x] стратегия не является только UI-тегом;
- [x] захват полок создаёт реальный контракт;
- [x] инновация создаёт реальный продукт;
- [x] сокращение долга меняет кассу и долг;
- [x] память влияет на доверие между контрагентами;
- [x] хроника доступна в разделе мира;
- [x] schemaVersion 12 мигрирует на 13.

## Негативные сценарии

- компания без денег не запускает дорогую продуктовую линию;
- компания без продукта не создаёт фиктивный контракт на полку;
- одинаковая операция одного дня не создаёт бесконечные дубликаты памяти;
- контролируемая игроком компания не теряет активы из-за фоновой покупки NPC.

## Данные и состояние

`EcosystemState.intelligence` владеет руководителями, стратегиями, отношениями, памятью и хроникой. UI только отображает эти данные.

## Не входит в задачу

- ручное назначение директоров игроком;
- политические и законодательные события;
- глобальные климатические кризисы.

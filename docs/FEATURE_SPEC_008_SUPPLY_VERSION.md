# Feature Spec 008 — сырьё, поставщики и обязательное обновление

## Проблема

Производство использовало абстрактную себестоимость и не зависело от реального склада. Установленная PWA могла продолжать работать на старом кэше после релиза.

## Наблюдаемое поведение

- игрок закупает конкретные варианты солода, хмеля, дрожжей, яблок, сахара и бутылок;
- заказ оплачивается сразу и доставляется через игровые дни;
- поставка может задержаться;
- точное качество раскрывается при доставке;
- сырьё хранится отдельными лотами с происхождением, ценой и сроком годности;
- запуск партии требует достаточного количества сырья;
- игрок может выбрать предпочтительный лот или оставить автоматический подбор;
- партия хранит фактически использованные лоты и их стоимость;
- качество сырья влияет на риск дефектов, чистоту и характер продукта;
- розлив требует бутылок со склада;
- цены, наличие, сроки и ожидаемое качество предложений меняются по дням;
- повторные закупки развивают отношения с поставщиком;
- постоянный договор даёт скидку и более короткий срок;
- клиент проверяет `version.json` при запуске, фокусе, возвращении из фона и раз в минуту;
- при несовпадении версии интерфейс блокируется обязательным обновлением;
- обновление очищает PWA-кэш, снимает старый service worker и перезагружает приложение;
- сохранение IndexedDB не удаляется.

## Критерии приёмки

- [x] Без сырья партия не запускается.
- [x] Доставка создаёт складской лот с фактическим качеством.
- [x] Производство списывает точное количество из лотов.
- [x] Фактическая себестоимость партии строится из сырья и процесса.
- [x] Без бутылок розлив заблокирован.
- [x] Сохранения schemaVersion 1–4 мигрируют на schemaVersion 5.
- [x] Новая версия PWA обнаруживается без ручной очистки браузера.
- [x] Обновление является обязательным, но не удаляет прогресс.

## Негативные сценарии

- заказ ниже минимального объёма;
- заказ больше доступного остатка поставщика;
- недостаточно денег;
- задержка доставки;
- порча просроченного сырья;
- недостаточный складской остаток;
- недоступность `version.json` не блокирует игру;
- повреждённое старое сохранение не принимается как актуальное.

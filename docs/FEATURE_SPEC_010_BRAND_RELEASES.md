# Feature Spec 010 — бренды, упаковка и продвижение

## Наблюдаемое поведение

- игрок создаёт бренд отдельно от компании;
- разлитая партия получает коммерческий релиз, упаковку и цену;
- бренд и оформление влияют на оценку закупщика;
- кампании требуют денег и завершаются по игровым дням;
- узнаваемость релиза и бренда растёт после завершения кампании;
- все экраны остаются компактными и прокручиваемыми на телефоне.

## Критерии приёмки

- сохранения schemaVersion 1–6 мигрируют на 7;
- нельзя создать релиз без бренда и разлитой партии;
- нельзя запустить две кампании одновременно для одного релиза;
- затраты отражаются в финансах;
- UI использует чёрно-серо-бордовую гамму без разноцветного декоративного шума.

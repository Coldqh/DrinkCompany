# Feature Spec 018 — Ecosystem Kernel Reset

## Проблема

Симуляция выросла быстрее единого ядра. Организации, товары, деньги, поставки и история распределены между несколькими модулями. Добавление десятков отраслей алкоголя и сотен коктейлей через новые union-типы и условные ветки приведёт к дублированию правил.

## Наблюдаемое поведение

- Мир получает единый сериализуемый `EcosystemKernelState`.
- Все организации, объекты, продукты, лоты и контракты имеют единый реестр идентичности.
- Денежное движение записывается двойной проводкой debit/credit.
- Товарное движение записывается отдельно от текущего остатка.
- Лоты входят в граф прослеживаемости.
- Симуляция использует детерминированный seed.
- Дневные, месячные, сезонные и годовые процессы планируются через scheduler.
- Категории напитков, технологические цепочки и коктейли задаются данными.
- Сохранения schemaVersion 13 мигрируют на 14 без потери текущего игрового состояния.

## Критерии приёмки

- [x] каталог поддерживает пиво, сидр, вино, крепкие напитки, ликёры, RTD, no/low и миксеры;
- [x] коктейль ссылается на категорию или конкретный продукт, а не на отдельный тип класса;
- [x] одинаковый seed даёт одинаковую последовательность случайных чисел;
- [x] повторная синхронизация поставки не создаёт двойные проводки;
- [x] граф происхождения возвращает всю цепочку родителей;
- [x] observer-run на 1095 дней не нарушает инварианты ядра;
- [x] kernel автоматически восстанавливается для старого сохранения.

## Не входит в задачу

- полный перенос player-market из `WorldState`;
- сотни готовых коктейлей;
- отдельные производственные правила всех категорий;
- государство, сельское хозяйство и население.

Эти слои будут добавляться поверх kernel, а не параллельно ему.

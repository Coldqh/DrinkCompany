# Feature 009 — развитие объекта и единая визуальная система

## Проблема

Производство росло только через покупку отдельных модулей. Помещение не имело состояния, обслуживание не влияло на выпуск, а цветовая система интерфейса распадалась на несвязанные синие, зелёные, фиолетовые и оранжевые акценты.

## Наблюдаемое поведение

- у компании есть производственный объект с помещениями, инфраструктурой, чистотой и состоянием оборудования;
- расширение увеличивает мощность, объём партии, склад и контроль качества;
- ежедневная работа изнашивает оборудование и снижает санитарное состояние;
- критически изношенный модуль блокирует запуск;
- обслуживание и мойка требуют денег;
- сохранённый рецепт можно поставить в очередь для автоматической попытки запуска после перехода дня;
- UI использует единую графитово-бронзовую гамму, сохраняя отдельный красный только для ошибок и критических состояний.

## Критерии приёмки

- [x] состояние объекта хранится в GameState;
- [x] старые сохранения v1–v5 мигрируют в schemaVersion 6;
- [x] помещения и инфраструктура имеют уровни и стоимость;
- [x] состояние оборудования влияет на точность и мощность;
- [x] санитария влияет на качество партии;
- [x] склад имеет ограничение вместимости;
- [x] есть сервис, мойка, модернизация и очередь;
- [x] интерфейс разделён на Объект / Линии / Сервис / Рост;
- [x] цветовая система сведена к одной гамме;
- [x] доменная логика покрыта тестами.

## Негативные сценарии

- недостаточно денег на расширение;
- помещение или инфраструктура уже на максимальном уровне;
- оборудование не установлено;
- модуль не нуждается в обслуживании;
- склад переполнен;
- очередь не может запуститься из-за сырья, места или поломки;
- критический износ блокирует производство.

## Данные и состояние

`FacilityState` владеет помещениями, инфраструктурой, санитарией, износом и модернизациями. `ProductionState.queue` владеет планом следующих запусков.

## Не входит в задачу

- строительная сетка и свободная расстановка стен;
- сотрудники и смены;
- переезд между объектами;
- ремонт с ожиданием нескольких дней.
